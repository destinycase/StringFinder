## 이 버전이 갖춘 기능

- **빠른 병렬 검색:** Rust 엔진이 폴더를 병렬로 검색합니다. 큰 파일은 메모리 매핑으로 읽어 전체 내용을 복사하지 않습니다.
- **검색 설정:** 하나의 메뉴에서 기본 검색(권장)과 변형 글자 검색(느림, 유니코드 정규화·대소문자 확장까지 비교)을 고르고, 값만 검색 모드를 함께 고릅니다.
- **값만 검색:** JSON·XML 값, Excel(XLSX/XLSM/XLS/XLSB) 셀 값, UE 현지화 archive의 원문·번역문을 부분 일치·정확히 일치로 검색합니다. archive 결과는 줄 번호·Namespace·Key·원문·번역문으로 표시합니다.
- **결과 보기:** 파일·위치·값 단위 결과, 결과 필터링·정렬, 문맥 미리보기, 외부 편집기로 열기, 실패를 정상 완료·결과 없음과 구분한 상태 표시를 제공합니다.
- **필터:** 검색 폴더·확장자·파일명 목록을 끌어서 순서를 바꾸고, 검색 폴더를 그룹으로 묶어 한꺼번에 선택·해제합니다. 값만 검색을 쓰는 동안에는 확장자 필터 안내를 표시합니다.
- **저장과 내보내기:** 탭별 검색 세션을 저장·복원하고, 결과를 TXT·XLSX로 내보냅니다.
- **환경:** 한국어·English 화면, 문자 인코딩 설정, Windows 연결 폴더(정션) 포함 여부, 설정 기반 성능 진단 리포트를 제공합니다.
