# StringFinder 설계 검토 기록

정리일: **2026-10-04**. 반려·취소·보류한 접근과 이유를 기록합니다. 채택한 설계는 [개발자 가이드](DEVELOPER_GUIDE.md#5-현재-설계로-이어진-결정), 현재 계약은 [구현 정책](IMPLEMENTATION_POLICY.md)에 있습니다.

## 1. 상태와 판단

**미채택**은 검토했지만 최종 구현에 넣지 않은 방식, **보류**는 근거 부족 또는 작업 중단 상태, **제거**는 적용했던 기능을 없앤 상태입니다. 보류를 효과 없음으로 해석하지 않습니다.

| 접근 | 상태·시점 | 이유·근거 | 현재 선택·재검토 조건 |
| --- | --- | --- | --- |
| 모든 UTF-8 입력의 선행 전체 검사 | 미채택 · 5.9.25 후속 작업본 | 존재 확인도 파일 끝까지 접근. Set D 0.395초·541.1MB로 메모리 임계값 초과 | ASCII 부분 검색 샘플 판정·결과 검증, 이상 시 전체 재확인. 성능 기록 2절 |
| XLSX 전체 ZIP/XML 사전 검사 | 미채택 · 6.0.3 | 추가 읽기 비용 | 공개 셀 reader로 실제 셀을 한 번 읽음 |
| 파일 크기·dimension에 따른 Excel 혼합 경로 | 미채택 · 6.0.3 | 작은 파일도 넓은 범위를 가질 수 있어 정확성 보장 불가 | XLSX/XLSM 실제 셀 수집, XLS/XLSB 기존 Range |
| 모든 인코딩으로 반복 검색 | 미채택 · 현재 정책 | 비교 비용, 오해석·중복 결과와 위치·문맥 모호함 | 자동 감지와 명시적 지정. 정상 입력의 내용·위치·오류·성능 비교 필요 |
| Excel 존재 확인 셀 개수 상한 복구 | 미채택 · 현재 정책 | 뒤쪽 매치 누락 가능 | 첫 매치까지 탐색. 과거 API 인자는 호환용 |
| 저장 세션 지연 복원 | 보류 · 시작 화면 개선 | 활성 탭·결과·저장·종료 계약에 영향, 실제 병목 미확정 | 모두 복원 유지. 병목 확인 후 별도 설계 |
| 진단용 시작 시간 계측 | 제거 · 6.0.1 | 진단 계측·리소스 정리 결정 | 첫 Paint 이후 로그 정리 유지. 과거 측정은 성능 기록 7절 |

## 2. 근거가 제한적인 과거 후보

| 후보 | 현재 상태와 재검토 시 주의점 |
| --- | --- |
| XLSX 압축 파일 메모리 예산·네이티브 후보 | 과거 실험 기록이며 제품 기본 최적화로 채택되지 않았습니다. 속도뿐 아니라 메모리·손상 입력·취소를 함께 비교해야 합니다. |
| 동일 파일 핸들 재사용·Calamine 입력 경로 | 검토 기록은 있지만 확인 가능한 채택 근거·개선 수치가 없어 효과를 단정하지 않습니다. |
| 소형 XML 묶음 처리 | XML 특수 검색의 파일별 반복 비용을 줄일 후보로 논의했으나 최적화 작업을 중단했습니다. 일반 텍스트 검색과 혼동하지 않으며 적용 완료로 기록하지 않습니다. |

스킵 사유 모듈 분리와 리소스·손상 파일 QA는 유지보수·신뢰도 작업입니다. 측정을 수행했다는 이유만으로 검색 속도 최적화로 분류하지 않습니다. 관련 일반 변경은 개발 이력과 개발자 가이드에서 확인합니다.


## 3. 기록 규칙

접근 → 상태 → 검토/적용 버전 또는 작업본 → 이유와 근거 → 현재 대안 → 재검토 조건을 기록합니다. 이유가 확인되지 않으면 **근거 미확인**으로 남깁니다. 과거 XLSX 후보 보류와 6.0.3 공개 셀 API 채택처럼 다른 접근과 적용 시점을 구분합니다.
