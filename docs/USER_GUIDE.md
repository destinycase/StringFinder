# StringFinder 사용자 가이드

- **대상:** Windows에서 파일을 검색하는 일반 사용자
- **기준 버전:** StringFinder 5.9.21
- **최종 수정일:** 2026-09-25

---

## 1. StringFinder로 할 수 있는 일

StringFinder는 선택한 폴더와 파일에서 단어나 문장을 찾아 파일 이름, 위치, 주변 내용을 보여주는 Windows 프로그램입니다. 일반 문서와 코드뿐 아니라 JSON, XML, Excel 파일도 검색할 수 있습니다.

검색 결과가 화면에 표시되어도 파일을 수정하지는 않습니다. 결과를 살펴본 뒤 필요하면 원본 파일을 열거나 검색 결과를 별도 파일로 저장할 수 있습니다.

## 2. 처음 검색하기

1. 왼쪽 **폴더 목록**에 검색할 폴더를 추가합니다. 폴더를 여러 개 선택해도 됩니다.
2. 위쪽 검색 칸에 찾을 단어나 문장을 입력합니다.
3. 왼쪽 **확장자 필터**에서 찾을 파일 종류를 선택합니다. 목록을 비워 두면 확장자가 있는 파일과 없는 파일을 모두 대상으로 합니다.
4. 필요하면 **파일명 필터**에 찾고 싶은 파일 이름을 추가합니다. 예를 들어 `invoice`를 추가하면 파일 이름에 그 글자가 들어간 파일로 검색 범위를 좁힐 수 있습니다.
5. **검색**을 누릅니다. 검색 중에는 진행 상태가 표시되고, 결과가 차례로 화면에 추가됩니다.

일반 문서에서는 파일 이름과 확장자 필터를 먼저 좁히면 결과를 찾기 쉽고 불필요한 검색도 줄어듭니다. 검색 조건이 맞지 않아 결과가 없다면 폴더와 필터를 먼저 확인하세요.

## 3. 화면과 검색 결과 보기

- 파일 목록에서 파일을 선택하면 그 파일에서 찾은 위치가 아래 검색 결과에 표시됩니다.
- 검색 결과를 선택하면 가능한 경우 주변 내용을 미리 볼 수 있습니다. Excel 결과는 시트·셀·값으로 표시됩니다.
- 요약에는 검색한 파일과 검색 결과 수, 걸린 시간이 표시됩니다.
- **건너뛴 파일 수**가 보이면 일부 파일을 읽지 못했거나, 안전 한도 때문에 파일의 일부만 검색했다는 뜻일 수 있습니다. **파일 목록 보기**를 눌러 파일 이름과 이유를 확인하고, 필요하면 **목록 전체 복사**로 복사하세요.
- **결과 수량 제한 도달** 안내는 전체 결과 개수가 설정한 한도에 도달했다는 뜻입니다. 건너뛴 파일 안내와는 별도로 표시되며 둘 다 함께 나타날 수 있습니다.
- 로그 창은 상태 표시줄의 **로그** 버튼으로, 설정 창은 오른쪽 끝의 **설정** 버튼으로 엽니다.

검색 중에는 현재 검색이 끝나거나 중지될 때까지 검색 조건을 바꾸거나 다른 탭에서 검색을 시작할 수 없습니다. 새 탭은 탭 영역을 마우스 오른쪽 버튼으로 눌러 추가하거나 `Ctrl + T`를 사용하세요.

**목록 조밀하게**는 기본적으로 사용하도록 설정되어 있습니다. 글자 크기는 그대로 두고 결과와 왼쪽 목록의 여백을 줄여 한 화면에 더 많은 항목을 보여줍니다. 설정에서 바꾸면 열려 있는 검색 탭에도 바로 적용됩니다.

## 4. 검색 방식 고르기

검색어 입력 칸 왼쪽의 검색 방식 목록에서 **일반 검색** 또는 **누락 방지 검색(매우 느림)**을 선택합니다.

- **일반 검색:** 대부분의 한글·영어 문서와 코드에 권장하는 기본 방식입니다. 빠른 검색이 필요할 때 사용하세요.
- **누락 방지 검색(매우 느림):** 일반 검색에서 예상한 글자를 찾지 못했을 때 시도해 보세요. 한글 글자 표현이 서로 다르거나, 독일어 `ß`와 `ss`처럼 특수한 대소문자 관계가 있는 경우, 일부 오래된 문서의 글자 인코딩이 일정하지 않은 경우에 도움이 될 수 있습니다. 검색 범위와 파일 크기에 따라 오래 걸릴 수 있습니다.
- **존재만 확인:** 검색어가 들어 있는 파일이 있는지만 빠르게 확인합니다. 파일 안의 모든 위치나 문맥을 모으지 않으므로, 파일별 상세 위치가 필요하면 체크를 끄세요.

누락 방지 검색은 평소 기본값으로 사용할 필요가 없습니다. 먼저 일반 검색을 시도하고, 결과가 없는데 파일에 글자가 있는 것이 확실할 때만 해당 파일이나 좁은 폴더에서 사용하면 기다리는 시간을 줄일 수 있습니다.

## 5. JSON, XML, Excel 검색

왼쪽 **특수 검색** 목록에서 파일 종류와 검색 방법을 선택합니다. 특수 검색을 선택하면 해당 종류의 파일을 대상으로 합니다. 일반 모드에서 고른 확장자 목록은 특수 검색에 적용되지 않습니다.

| 선택 | 무엇을 보여주나요? | 예시 |
| --- | --- | --- |
| JSON | 값이 있는 위치와 값 | `/items/0/name`, `Alice` |
| XML | 태그 또는 속성의 위치와 값 | `/root/user/@id`, `123` |
| Excel | 시트 이름, 셀 주소, 셀 값 | `Sheet1`, `B12`, `Alice` |

각 형식에는 **부분 일치**와 **정확히 일치**가 있습니다. 부분 일치는 값 안에 검색어가 들어 있으면 찾고, 정확히 일치는 값 전체가 검색어와 같을 때 찾습니다.

- JSON 검색은 **값을 검색**합니다. 검색어가 키 이름에만 들어 있으면 그 이유만으로 결과가 나오지는 않습니다. 결과 위치에는 값을 담은 키 경로가 표시될 수 있습니다.
- Excel 미리보기는 검색할 때 찾은 시트와 셀 정보를 사용하므로, 선택할 때마다 원본 Excel 파일을 다시 읽지 않습니다. Excel 셀에는 일반 문서처럼 위·아래 문맥이 없어 해당 설정이 표시되지 않습니다.
- 올바르게 보이는 XML도 DTD 선언(`<!DOCTYPE ...>`)을 사용하는 경우 검색할 수 없습니다. 안전을 위해 해당 선언과 사용자 정의 항목을 처리하지 않습니다. XML 파일을 직접 수정하기 어렵다면 파일을 만든 담당자에게 DTD 없이 저장할 방법을 문의하세요.
- JSON이나 XML의 구조가 잘못된 경우, 앞부분에서 검색어를 찾았더라도 파일 전체를 정상 결과로 보여주지 않습니다. 파일 목록 보기에서 이유를 확인하세요.

## 6. 파일 필터와 제외 설정

- **확장자 필터:** `txt`, `json`처럼 파일 종류를 선택합니다. 확장자를 하나도 선택하지 않으면 모든 종류의 파일이 대상입니다.
- **파일명 필터:** 원하는 이름 조각을 목록에 추가하고 체크해 검색 범위를 좁힙니다. 등록한 항목은 체크를 끄거나 삭제할 수 있습니다.
- **숨김 파일/폴더 제외:** 설정 → 고급 → 공통에서 사용 여부를 바꿉니다. 켜면 Windows에서 숨김으로 표시된 항목과 점(`.`)으로 시작하는 파일·폴더가 제외됩니다.
- **바이너리 파일 제외:** 이미지나 실행 파일처럼 일반 글자로 읽기 어려운 파일을 제외합니다. 필요한 파일이 결과에 나오지 않는다면 이 설정을 잠시 끄고 다시 확인할 수 있습니다.
- `.gitignore`나 `.ignore` 파일에 적힌 이름만으로는 검색에서 제외하지 않습니다. 숨김 제외, 확장자·파일명 필터 등 사용자가 고른 조건은 그대로 적용됩니다.
- 휴지통 안의 파일은 검색하지 않습니다. 같은 폴더를 여러 번 추가해도 같은 파일이 중복 표시되지 않습니다.

## 7. 결과 열기, 복사, 저장

- 파일 목록에서 파일을 **더블 클릭**하면 Windows 기본 프로그램으로 엽니다.
- 검색 결과 상세 항목을 **더블 클릭**하면 설정한 편집기에서 해당 위치를 엽니다.
- `.exe`, 스크립트, 바로가기처럼 열었을 때 실행될 수 있는 파일은 경고가 표시됩니다. 출처를 알고 신뢰하는 파일만 여세요.
- `Ctrl + C`는 선택한 파일 경로나 검색 결과 행을 복사합니다.
- 결과 영역을 마우스 오른쪽 버튼으로 눌러 `.txt` 또는 `.xlsx`로 내보낼 수 있습니다. Excel로 저장할 때 검색 결과가 수식으로 실행되지 않도록 일반 텍스트로 처리합니다.
- `Ctrl + T`로 새 검색 탭을 만들 수 있습니다. 프로그램을 정상적으로 종료하면 탭과 검색 상태가 다음 실행에 복원됩니다. 갑작스러운 종료 직전의 변경은 저장되지 않을 수 있습니다.

## 8. 설정

설정 창은 **일반**과 **고급** 탭으로 나뉩니다. 처음 사용하는 경우 기본값을 그대로 두는 것을 권장합니다.

### 일반

- **언어:** 한국어 또는 English를 선택합니다. 언어 변경은 프로그램을 다시 시작한 뒤 적용됩니다.
- **화면:** 목록 조밀하게 여부를 바꿉니다.
- **가이드:** GitHub 사용자 가이드 버튼을 누르면 기본 웹 브라우저에서 온라인 설명서를 엽니다.
- **로그:** 로그 보관 여부와 보관 개수·기간을 정하고, 저장된 로그를 확인하거나 삭제할 수 있습니다.
- **데이터:** **데이터 폴더 열기**로 설정과 저장된 검색 상태가 있는 폴더를 열 수 있습니다. **모든 데이터 삭제**는 설정·저장 상태·로그를 삭제하므로 필요한 데이터가 없는지 확인한 뒤 사용하세요.
- **성능 진단:** 실제로 사용하는 폴더에서 검색 속도 차이를 확인할 때 실행합니다. 한 번 실행하면 여러 검색 방식을 각각 5회 측정하고, 사람이 읽기 쉬운 요약과 자세한 자료를 저장할 수 있습니다. 측정 자료에는 검색한 파일의 이름과 내용은 담지 않지만, 컴퓨터 정보와 파일 종류·크기 분포가 포함될 수 있으므로 다른 사람에게 보내기 전에 내용을 확인하세요.

### 고급

- **전체 검색 결과 수 제한:** 한 검색에서 표시할 전체 결과 수의 상한입니다. 기본값은 500,000건입니다.
- **파일당 검색 결과 수 제한:** 한 파일에서 표시할 결과 수의 상한입니다. 기본값은 10,000건입니다. 한도를 높이면 더 많은 결과를 볼 수 있지만 화면 표시와 저장이 느려질 수 있습니다.
- **검색 파일 크기 제한:** 기본값은 1GB이며 모든 검색 방식과 파일 종류에 적용됩니다. 이보다 큰 파일은 검색하지 않습니다. 이 값은 파일 자체의 크기 기준이지, 필요한 메모리 양을 뜻하지 않습니다.
- **JSON 최대 깊이 제한:** 매우 복잡하게 중첩된 JSON 파일에서 너무 깊은 부분까지 처리하지 않도록 제한합니다. 기본값 사용을 권장합니다.
- **누락 방지 검색 전용 설정:** 작은 텍스트 파일과 큰 JSON을 처리하는 방식, 검색 대기 시간, Excel 파일 동시 처리 수를 조절합니다. 주로 속도와 메모리 사용에 영향을 주며 검색 결과의 의미를 바꾸기 위한 설정은 아닙니다. 특별한 문제가 없다면 기본값을 유지하세요.

설정 범위를 벗어난 값은 프로그램이 안전한 기본값으로 되돌릴 수 있습니다. 설정 파일을 직접 수정하는 것보다 설정 창을 이용하세요.

## 9. 자주 묻는 질문

**검색 결과가 없지만 파일에 글자가 있는 것 같습니다.**

검색 폴더, 확장자 필터, 파일명 필터를 확인하세요. 특수 검색을 선택했다면 파일 종류가 맞는지도 확인합니다. 숨김 파일이나 바이너리 파일 제외 설정 때문에 빠졌을 수 있습니다. 조건이 맞는데도 일반 검색에서 찾지 못하면 해당 파일만 대상으로 **누락 방지 검색(매우 느림)**을 시도해 보세요.

**“건너뛴 파일 수”가 표시됩니다. 검색이 실패한 건가요?**

검색 전체가 실패했다는 뜻은 아닙니다. 일부 파일을 열 수 없었거나, 너무 크거나 복잡해서 검색하지 못했을 수 있습니다. **파일 목록 보기**를 눌러 파일마다 표시된 이유를 확인하세요. 일부 파일은 결과가 표시되더라도 파일당 결과 수 제한 등에 걸려 전부 검색되지 않았을 수 있으므로 안내 목록도 확인하는 것이 좋습니다.

**“결과 수량 제한 도달”은 무슨 뜻인가요?**

전체 검색 결과가 설정한 최대 개수에 도달해 검색이 멈췄다는 뜻입니다. 건너뛴 파일이 있다는 뜻과는 다릅니다. 검색 범위를 좁히거나 설정 → 고급에서 전체 검색 결과 수 제한을 높이세요.

**검색 중 화면이 한동안 바뀌지 않습니다.**

파일 수가 많거나 큰 파일을 처리하면 오래 걸릴 수 있습니다. 검색 상태와 경과 시간을 확인하세요. 계속 기다리기 어렵다면 **중지**를 누르세요. 중지 요청도 현재 처리 중인 파일 작업이 정리된 뒤 완료될 수 있습니다.

**“누락 방지 검색(매우 느림)”은 언제 사용하나요?**

일반 검색에서 결과가 없는데 검색어가 파일에 있는 것이 확인된 경우에 사용합니다. 한글 표현 방식이 다르거나 `ß`와 `ss`처럼 특수한 문자 관계가 있는 글자, 일부 오래된 인코딩의 문자를 찾을 때 도움이 될 수 있습니다. 평소에는 일반 검색이 더 빠릅니다.

**Excel 파일에서 파일은 찾았는데 셀 위치가 필요합니다.**

검색 방식이 **존재만 확인**으로 설정되어 있지 않은지 확인하세요. 존재만 확인을 켜면 파일에 검색어가 있는지만 표시하고 모든 셀 위치를 모으지 않습니다. 셀 주소와 값을 보려면 존재만 확인을 끄고 특수 검색을 Excel로 선택하세요.

**JSON에서 키 이름만 검색해도 결과가 나오나요?**

JSON 검색은 값의 내용을 찾습니다. 예를 들어 `"name": "Alice"`에서 `Alice`를 찾을 수 있지만, `name`이 키로만 등장하는 경우에는 검색 결과가 되지 않습니다.

**XML 파일이 검색되지 않고 DTD 관련 안내가 나옵니다.**

해당 XML이 DTD 선언이나 사용자 정의 항목을 사용한다는 뜻입니다. StringFinder는 이를 처리하지 않습니다. 파일을 관리하는 담당자에게 DTD 없이 내보내 달라고 요청하거나, 내용을 변경해도 되는 경우 안전한 XML 도구로 일반 값으로 바꾼 사본을 검색하세요.

**이전에 사용하던 검색 탭을 다시 볼 수 있나요?**

프로그램을 정상적으로 종료했다면 다음 실행에서 저장된 탭과 검색 상태가 복원됩니다. 프로그램을 강제로 종료했다면 마지막 변경이 저장되지 않을 수 있습니다.

**문제가 계속되면 어떻게 하나요?**

먼저 **파일 목록 보기**에서 건너뛴 이유를 확인하고, 추가 정보가 필요하면 상태 표시줄의 **로그**를 확인하세요. 로그나 성능 진단 자료를 다른 사람에게 보낼 때는 개인 경로나 컴퓨터 정보가 포함되어 있지 않은지 살펴보세요.

## 10. 단축키

| 동작 | 방법 |
| --- | --- |
| 검색 시작 | 검색어 입력 후 `Enter` |
| 새 검색 탭 추가 | `Ctrl + T` 또는 탭 영역에서 마우스 오른쪽 버튼 → 탭 추가 |
| 선택한 결과 복사 | `Ctrl + C` |
| 파일 열기 | 파일 목록에서 더블 클릭 |
| 검색 결과 위치 열기 | 검색 결과 상세에서 더블 클릭 |
