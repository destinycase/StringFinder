# StringFinder 성능 기록

7.1.1부터 [벤치마크 기준선](BENCHMARK_BASELINE.md)과 비교한 측정 결과를 기록합니다. 6.x의 기록은 [v7 이전 성능 기록](archive/before-v7/PERFORMANCE_HISTORY.md)에 있습니다.

기록 방법: 측정 버전·날짜, 기준선 대비 비율의 범위, "결과 다름"·"느려짐" 표본과 원인, 측정 범위 밖의 한계를 적습니다. 원본 JSON은 내부 보고서에 둡니다.

## 1. v7.1.1 · 기준선 설정 (2026-11-13)

- 새 도구 `tools/benchmark.py`로 33개 표본을 16회차씩 세 번 쟀습니다. 2·3회차가 서로 0.92~1.09배로 일치해 3회차를 기준선으로 정했습니다.
- 모든 회차에서 표본별 결과 지문이 같았습니다(회차·측정 사이 결과 변동 없음).
- 처음 회차는 빌드 직후라 약 18% 느렸습니다. 측정 전 장비가 쉬고 있어야 한다는 점을 판정 규칙에 반영했습니다.
- 한계: 엔진 폴더 검색만 잽니다. 앱의 결과 정리·화면·저장 시간은 이 기록에 나오지 않습니다.
