# 5차 안정 버전 — v7.4.1

선언일: **2026-11-19** · 이전 기준판: [v7.3.1](master-baseline-v7.3.1.md)

v7.4.1을 StringFinder의 다섯 번째 안정 버전으로 지정합니다. 코드는 7.3.4와 같고 버전 표기만 7.4.1로 올려 다시 빌드했습니다. 두 번째 숫자는 사용자가 정했습니다. 이 문서는 선언 뒤에는 오탈자·깨진 링크만 고칩니다.

## v7.3.1 이후 바뀐 기능

- **XML 미리보기 색(7.3.2):** 문맥 미리보기에서 XML 태그와 주석에 색이 들어갑니다. 전에는 한 글자 태그에만 색이 들어갔습니다.
- **로그 보관 기본값(7.3.2):** 설정 파일에 로그 보관 값이 없을 때 쓰는 값을 설정 창의 기본값(10개·3일)과 맞췄습니다.
- **빌드한 PC 경로를 남기지 않음(7.3.3):** 검색 엔진 파일에 빌드한 PC의 라이브러리 경로(Windows 계정 이름 포함)가 들어가던 것을 고쳤습니다. 이 버전의 실행 파일에는 빌드한 PC의 경로가 없습니다. 7.3.1 이전 실행 파일에는 남아 있습니다.
- **"모든 데이터 삭제" 보강(7.3.4):** 예전 설정을 불러올 때 만든 백업 파일도 함께 지웁니다.
- **시트 이름의 `|`(7.3.4):** 이름에 `|`가 든 Excel 시트를 읽지 못했을 때, 건너뛴 안내에 시트 이름이 잘리지 않고 그대로 나옵니다.
- **로그 문구(7.3.4):** 영어로만 남던 로그 6곳이 다른 로그처럼 화면 언어에 맞는 문구로 남습니다.
- **검색 엔진 속도:** 같은 표본의 검색 결과가 7.3.1과 같고, 새로 잰 기준선은 7.3.1 기준선의 0.91~1.11배입니다([성능 기록](PERFORMANCE_HISTORY.md)).

## 업데이트할 때

- 세션 저장 형식은 7.3.1과 같습니다(형식 3). 7.3.1에서 저장한 탭은 결과와 함께 그대로 열리고, 7.4.1에서 저장한 탭도 7.3.1에서 열립니다.
- 7.2.1 이전 버전에서 저장한 탭은 7.3.1과 마찬가지로 검색 조건만 불러오고 결과는 한 번 비워집니다.

## 알려진 제약

- JSON 키 안의 `.`은 중첩 경로와 같은 글자로 보입니다.
- 머리글 정렬 기준은 세션에 저장되지 않습니다.
- 결과가 아주 많을 때 백그라운드 저장 중(1~2초) 화면 반응이 조금 느려질 수 있습니다.
- 수천 개 파일(수십만 건)을 한꺼번에 고른 상태에서 상세 목록을 거르면 입력이 멈춘 뒤 1~2초 걸립니다.
- 검색이 진행 중일 때 결과가 들어와 파일 목록이 다시 만들어지면, 여러 개 고른 선택이 보던 파일 하나로 풀립니다.

성능 기준값은 [벤치마크 기준선](BENCHMARK_BASELINE.md), 버전별 변경은 [개발 히스토리](DEVELOPMENT_HISTORY.md)에 있습니다.
