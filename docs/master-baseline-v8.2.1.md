# 10차 안정 버전 — v8.2.1

선언일: **2026-11-28** · 이전 기준판: [v8.1.1](master-baseline-v8.1.1.md)

v8.2.1을 StringFinder의 열 번째 안정 버전으로 지정합니다. 코드는 8.1.7과 같고 앱 버전 표기만 8.2.1로 올렸습니다. 이 문서는 선언 뒤에는 오탈자·깨진 링크만 고칩니다.

## 기준 소스와 배포물

- 기준 태그: `v8.2.1` (이 문서를 추가한 선언 커밋).
- 제품 기준 커밋(8.1.7): `319a342fe9ad0b36d08989dd3aec17ecc8762ca8`. 선언 커밋은 여기에 앱 버전 표기·문서·벤치마크 기준선과 테마 옮겨 적기 도구의 줄바꿈 정리만 더합니다.
- 앱 버전 **8.2.1**, 엔진 버전 **1.0.2**. 창 제목에 `StringFinder v8.2.1 (Engine v1.0.2)`으로 보입니다.
- 배포 파일: `StringFinder-v8.2.1.exe` (Windows 단일 실행 파일). GitHub [Releases](https://github.com/destinycase/StringFinder/releases)에 첨부합니다.

| `StringFinder-v8.2.1.exe` | 72093960 | `d2b3159205e42bd9f6b3f9957e1f90bfff0c53460697163a199561df29b9d792` |

포함된 Rust 엔진(`sf_engine.pyd`, 엔진 1.0.2)의 SHA-256은 `9fc97ddcc188063fde7c36697cd2eb8ad5d32bcd23758947c69fb644f96983b1`이고, 엔진 소스 지문(`SOURCE_HASH`)은 `9d07cb0e58a58f57`입니다. 엔진은 8.1.6에서 만든 것과 같은 파일입니다.

## v8.1.1 이후 바뀐 기능

검색 결과는 8.1.1과 같습니다. 이번 판은 주로 내부 정리(기술 부채 해소)입니다.

- **화면 테마 내장(8.1.2)**: 화면 테마를 외부 라이브러리(pyqtdarktheme) 없이 앱 안에 넣었습니다. 다크·라이트 화면은 8.1.1과 픽셀 단위로 같고, 테마를 읽는 시간이 줄었습니다(한 번 잰 값으로 약 0.6초 → 0.003초. 앱 전체 기동 시간을 잰 것은 아님).
- **테마 전환 시 미리보기 강조(8.1.7)**: 테마를 바꾸면 미리보기에서 이미 강조된 현재 줄의 배경색도 바로 새 테마 색으로 바뀝니다. 전에는 다른 줄을 누를 때까지 이전 테마 색이 남았습니다.
- **내부 구조 정리(8.1.3~8.1.6)**: 결과 화면 코드와 검색 엔진(엔진 1.0.0 → 1.0.2)을 역할별 파일·단계별 함수로 나눴습니다. 화면과 검색 동작은 같습니다.
- **검색 결과:** 33개 벤치마크 표본의 결과 지문·일치 수가 8.1.1과 같습니다. 속도는 [성능 기록](PERFORMANCE_HISTORY.md)에 있습니다.

## 업데이트할 때

- 설정과 세션 저장 형식은 8.1.1과 같습니다(세션 형식 3). 8.1.1에서 저장한 탭은 결과와 함께 그대로 열리고, 8.2.1에서 저장한 탭도 8.1.1에서 열립니다.

## 알려진 제약

- UTF-16·CP949 archive는 검색하는 동안 파일 전체의 UTF-8 사본을 만들어, 수 GB 파일은 메모리가 부족하면 건너뜁니다.
- JSON 키 안의 `.`은 중첩 경로와 같은 글자로 보입니다.
- 머리글 정렬 기준과 검색 상세에서 직접 끈 열 비율은 저장되지 않습니다(프로그램을 다시 켜면 기본값).
- 결과가 아주 많을 때 백그라운드 저장 중(1~2초) 화면 반응이 조금 느려질 수 있습니다.
- 수천 개 파일(수십만 건)을 한꺼번에 고른 상태에서 상세 목록을 거르면 입력이 멈춘 뒤 1~2초 걸립니다.

성능 기준값은 [벤치마크 기준선](BENCHMARK_BASELINE.md), 버전별 변경은 [개발 히스토리](DEVELOPMENT_HISTORY.md)에 있습니다.
