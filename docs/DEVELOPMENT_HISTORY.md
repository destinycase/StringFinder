# StringFinder 버전별 개발 히스토리

7.1.1부터 새로 기록합니다. 6.4.20까지의 이력은 [v7 이전 개발 히스토리](archive/before-v7/DEVELOPMENT_HISTORY.md)에 있습니다.

## v7.5.5 · 검색이 끝나도 고른 파일 유지

- 검색 중에 파일 목록에서 고른 파일(여러 개 포함)이 검색이 끝날 때 첫 번째 파일로 바뀌던 것을 고쳤습니다. 7.5.2는 검색 중 목록이 다시 만들어질 때만 선택을 지켰고, 검색 종료 때 첫 결과를 자동으로 고르는 단계가 선택을 풀고 있었습니다. 아무것도 고르지 않았다면 이전처럼 첫 파일을 고릅니다.

## v7.5.4 · 검색 상세 열 폭을 표 폭에 맞춤

- JSON·XML·Excel·UE archive 검색 상세에서 열 폭을 표 폭에 맞춰 나눠 가로 스크롤이 생기지 않습니다. 짧은 열(줄·이름·키)은 좁게, 값 열(UE archive는 원문·번역)이 남는 폭을 똑같이 나눕니다.
- 오른쪽 미리보기 창과의 경계를 옮기거나 창 크기를 바꾸면 열 폭이 따라 바뀝니다.
- 셀보다 긴 내용은 끝을 "…"로 줄이고, 마우스를 올리면 전체 내용을 보여 줍니다. 파일 목록의 긴 이름도 "…"로 줄어듭니다.
- 열 경계를 직접 끌면 그 비율을 기억해 다른 파일에도 씁니다(프로그램을 켜 있는 동안).

## v7.5.3 · 프로그램 전체 로그 창

- 로그 창이 검색 단위가 아니라 프로그램을 켠 뒤의 모든 로그(모든 탭의 검색, 시작·설정 로그)를 최근 5,000줄까지 보여 줍니다. 어느 탭에서 열어도 같은 내용이고, 검색을 새로 시작해도 비워지지 않습니다.
- **로그 지우기**를 누르면 모든 탭의 로그 창이 함께 비워집니다.
- 탭에 로그를 저장하지 않으며, 이전 실행의 로그는 로그 창에 다시 불러오지 않습니다.

## v7.5.2 · 검색 중 여러 개 선택 유지

- 검색이 진행 중일 때 결과가 들어와 파일 목록이 다시 만들어져도, 여러 개 고른 파일의 선택이 보던 파일 하나로 풀리지 않고 그대로 남습니다. 합쳐 보던 상세 목록도 그대로 유지됩니다.

## v7.5.1 · 6차 안정 버전

- 7.4.9를 **6차 안정 버전 7.5.1**로 지정했습니다. 코드는 7.4.9와 같고 버전 표기만 바꿨습니다. 7.4.1 이후 바뀐 기능은 [v7.5.1 고정 문서](master-baseline-v7.5.1.md)에 있습니다. `dist/StringFinder.exe`가 7.5.1로 바뀝니다.

## v7.4.9 · 폴더 그룹 개수 위치

- 검색 폴더 목록에서 그룹의 `(선택/전체)` 개수를 줄 오른쪽 끝이 아니라 그룹 이름 바로 오른쪽에 표시합니다.

## v7.4.8 · 사용 중인 archive 안전 처리와 안내 문구

- 다른 프로그램이 저장 중인 큰 archive를 검색 준비 단계에서 잠금 없이 읽지 않습니다. 이런 파일은 넉넉하게 메모리를 잡거나 건너뛰어 검색 도중 엔진이 멈출 위험을 없앴습니다.
- 사용 중이라 건너뛴 1GB 넘는 파일은 건너뛴 목록에 "다른 프로그램에서 사용 중"으로 표시됩니다(이전에는 메모리 맵 할당 실패로 표시).
- 인코딩을 UTF-8로 직접 고른 채 UTF-8이 아닌 큰 파일을 검색할 때 파일 크기만큼 메모리를 잠깐 쓰던 것을 없앴습니다.

## v7.4.7 · CP949 archive와 사용 중인 큰 파일의 메모리 보호

- CP949로 저장된 UE 현지화 archive는 검색 전에 파일 크기의 3배 메모리를 확보합니다. 이전에는 실제 필요량(약 2.7배)보다 적게 잡거나, 앞부분이 영문뿐이면 거의 잡지 않아 수 GB 파일에서 전체 검색이 메모리 보호로 멈출 수 있었습니다. 설정에서 고른 인코딩도 반영합니다.
- 다른 프로그램이 저장 중이라 읽기 전용으로 열 수 없는 1GB 넘는 파일은 통째로 메모리에 읽지 않고 건너뜁니다.

## v7.4.6 · XML 검색과 일치가 많은 검색 속도 개선

- XML 파일 검색이 약 20% 빨라졌습니다. 태그·속성 이름을 매번 복사하지 않고, 속성 이름은 일치했을 때만 만듭니다.
- 한 줄에 검색어가 여러 번 나오거나 일치가 수십만 건인 검색이 빨라졌습니다(85만 건 표본에서 약 33%). 같은 줄 내용을 다시 만들지 않고, 검색이 끝날 때 결과 전체를 한 번 더 복사하지 않습니다. 검색 결과는 그대로입니다.

## v7.4.5 · UE 현지화 archive 8GB까지 검색

- UE 현지화 archive(`.archive`)는 고급 설정의 "검색 파일 크기 제한"(최대 1GB)과 상관없이 8GB까지 검색합니다. 이전에는 1GB를 넘는 archive를 "파일이 너무 큼"으로 건너뛰었습니다.
- UTF-8로 저장된 archive는 파일 크기와 상관없이 적은 메모리로 검색합니다. UTF-16으로 저장된 archive는 검색하는 동안 파일 크기의 1.5배 안팎 메모리가 필요하며, 부족하면 메모리 부족으로 건너뜁니다.

## v7.4.4 · UE 현지화 archive 검색 메모리·속도 개선

- archive 파일을 검색할 때 문서 전체를 메모리에 쌓지 않고 읽으면서 바로 판정합니다. 890MB 시험 파일에서 최대 메모리가 약 2.7GB에서 0.87GB(대부분 파일 자체)로 줄었고, 검색 시간은 약 4.3초에서 2.7초로 줄었습니다. 검색 결과·줄 번호·형식 오류 안내는 그대로입니다.

## v7.4.3 · 정확히 일치 검색 속도 개선

- JSON·XML 값 검색에서 "정확히 일치"를 켰을 때, 한글처럼 변환이 필요 없는 값은 바로 비교해 더 빨라졌습니다. 같은 장비에서 이전 엔진과 번갈아 잰 결과 한글 JSON은 약 0.6배, 한글 XML은 약 0.73배 시간이 걸렸습니다. 검색 결과는 그대로입니다.

## v7.4.1 · 5차 안정 버전

- 7.3.4를 **5차 안정 버전 7.4.1**로 지정했습니다. 코드는 7.3.4와 같고 버전 표기만 바꿨습니다. 7.3.1 이후 바뀐 기능은 [v7.4.1 고정 문서](master-baseline-v7.4.1.md)에 있습니다. `dist/StringFinder.exe`가 7.4.1로 바뀌어, 바로 쓰는 실행 파일에도 빌드한 PC의 경로가 남지 않습니다.

## v7.3.4 · 데이터 삭제 보강, 시트 이름의 `|` 처리

- 설정의 "모든 데이터 삭제"가 예전 설정을 불러올 때 만든 백업 파일(`config_backup_before_import_*.json`)도 지웁니다.
- Excel 시트 이름에 `|`가 들어 있고 그 시트를 읽지 못했을 때, 건너뛴 안내에 시트 이름이 `|` 앞까지만 나오던 문제를 고쳤습니다.
- 영어로만 남던 로그 6곳을 다른 로그처럼 한국어·영어 문구로 남깁니다.

## v7.3.3 · 실행 파일에 빌드한 PC 경로를 남기지 않음

- 검색 엔진 파일에 빌드한 PC의 라이브러리 경로(Windows 계정 이름 포함)가 들어가던 것을 고쳤습니다. 이제 엔진과 실행 파일 어디에도 빌드한 PC의 경로가 남지 않습니다. 검색 동작은 바뀌지 않습니다.

## v7.3.2 · XML 미리보기 색 표시

- 문맥 미리보기에서 XML 파일의 태그(`<root>`, `<item id="1">` 등)와 주석에 색이 입혀지지 않던 문제를 고쳤습니다. 한 글자 태그에만 색이 들어갔습니다. 검색 결과와 검색어 강조는 영향이 없었습니다.

## v7.3.1 · 4차 안정 버전

- 7.2.9를 **4차 안정 버전 7.3.1**로 지정했습니다. 코드는 7.2.9와 같고 버전 표기만 바꿨습니다. 7.2.1 이후의 코드 정리, 바뀐 기능과 업데이트할 때 한 번 겪는 변화(예전 탭의 결과가 한 번 비워짐)는 [v7.3.1 고정 문서](master-baseline-v7.3.1.md)에 있습니다.

## v7.2.9 · 표식처럼 생긴 줄이 일치하면 파일 전체가 빠지던 문제

- `ERR_LOGIN_FAILED|…`처럼 `ERR_…|`로 시작하는 줄이 검색어와 일치하면, 그 파일의 결과가 모두 빠지고 "알 수 없는 오류로 건너뜀"으로 나오던 문제를 고쳤습니다(3차 안정 버전 7.2.1부터 있던 문제). 이제 그 줄과 같은 파일의 다른 일치가 모두 결과에 나옵니다.
- `__SF_`로 시작하는 줄도 같은 방식으로 잘못 읽힐 수 있던 경우(예: 짧은 줄이 일치 위치를 잃음)를 함께 고쳤습니다.
- 전체 결과 수 상한을 셀 때 긴 줄(4096바이트 초과)의 일치도 함께 셉니다. 화면의 일치 수와 같은 기준입니다.

## v7.2.8 · 줄바꿈이 든 시트 이름 사유 보존, 검색 모드 대소문자

- 이름에 줄바꿈이 든 Excel 시트를 일부 읽지 못한 경우, 탭을 다시 열면 그 안내가 사라지던 문제를 고쳤습니다.
- 세션 파일을 손으로 고쳐 검색 모드를 `json`·`EXCEL`처럼 적어도 해당 모드로 읽습니다.
- 5.9.17 이전 세션에 쉼표로 적힌 파일명 조건은 더 읽지 않습니다. 그 뒤 버전의 체크 목록은 그대로 복원됩니다.

## v7.2.7 · 건너뛴 사유 문장 만들기를 검색 코드에서 분리

- 건너뛴 사유를 문장으로 만드는 코드를 검색 코드와 다른 파일로 옮겼습니다. 화면과 검색 동작은 바뀌지 않습니다.

## v7.2.6 · 엔진 호출 방식 하나로 정리

- 검색 엔진을 옵션 객체 한 가지 방식으로만 부르고, 엔진이 알려 주는 결과 종류를 그대로 씁니다. 화면과 검색 동작은 바뀌지 않습니다.

## v7.2.5 · 건너뛴 사유를 코드로 저장

- 건너뛴 파일의 사유를 언어와 상관없는 형태로 저장해, 화면 언어를 바꾸면 사유도 그 언어로 보입니다. 7.2.5 이전에 저장된 탭은 검색 조건만 불러옵니다.

## v7.2.4 · 예전 결과 모양 읽기 정리

- 7.2.3 이전 형식의 결과·필터 모양을 읽던 코드를 정리했습니다. 화면과 검색 동작은 바뀌지 않습니다.

## v7.2.3 · 세션 형식 번호, 예전 세션은 검색 조건만

- 7.2.3 이전에 저장된 검색 탭은 검색어·폴더·필터·검색 모드 같은 검색 조건만 불러오고, 결과는 비운 채 다시 검색하라고 안내합니다.
- 검색 모드를 언어와 상관없는 값으로 저장해, 화면 언어를 바꿔도 같은 모드로 열립니다.

## v7.2.1 · 3차 안정 버전

- 7.1.34를 **3차 안정 버전 7.2.1**로 지정했습니다. 코드는 7.1.34와 같고 버전 표기만 바꿨습니다. 7.1.1 이후 바뀐 기능과 알려진 제약은 [v7.2.1 고정 문서](master-baseline-v7.2.1.md)에 있습니다.

## v7.1.34 · 설정 불러오기 저장 보강

- 설정을 불러와 저장하는 순간 다른 저장이 끼어들어 불러온 설정이 예전 값으로 덮일 수 있던 드문 경우를 막았습니다.

## v7.1.33 · 설정 불러오기 안전성, 큰 상세 목록 거르기

- 설정 불러오기의 저장이 실패하면 지금 설정이 그대로 유지됩니다. 이전에는 실패 안내 뒤에도 불러온 값이 나중에 저장될 수 있었습니다.
- 불러오기 창에 줄 열기 프로그램이 바뀌는 경우 그 경로를 보여 줍니다. 불러오기 전 백업은 최근 5개만 남깁니다.
- 결과가 아주 많을 때 상세 목록 거르기 칸에 입력하면, 입력이 멈춘 뒤 한 번만 걸러 화면이 매번 멈추지 않습니다.

## v7.1.32 · 설정 창 항목 재배치

- 로그 설정과 **데이터 폴더 열기**·**모든 데이터 삭제**를 고급 탭으로 옮겼습니다. 일반 탭의 설정 내보내기·불러오기는 **설정 관리** 묶음으로 모았습니다.

## v7.1.31 · 설정 불러오기 창 정리

- 설정 불러오기 창을 **파일 정보**와 **불러올 항목** 묶음으로 나누고, 항목 이름과 설명을 두 칸으로 맞춰 정렬했습니다.

## v7.1.30 · 설정 내보내기·불러오기, 없는 폴더 표시

- 설정 → 일반에 **설정 내보내기…**·**설정 불러오기…**를 추가했습니다. 설정, 창 크기, 검색 조건, 검색어 기록을 파일 하나로 옮길 수 있고, 불러올 때 묶음을 골라 가져옵니다. 예전 버전 파일도 불러올 수 있으며, 불러오면 프로그램이 종료되고 다시 시작할 때 적용됩니다.
- 검색 폴더 목록에서 지금 PC에 없는 폴더에 ⚠를 표시합니다.

## v7.1.29 · 폴더 열기 실패 안내, 깊은 archive 안내 정정

- 파일 목록 오른쪽 메뉴의 **폴더 열기**가 파일이 없어졌거나 탐색기를 실행하지 못하면 아무 반응이 없던 것을, 안내 창으로 알리도록 고쳤습니다. 탐색기를 띄우는 동안 화면이 기다리지 않습니다.
- UE 현지화 archive가 너무 깊게 중첩돼 검색하지 못한 경우 "archive 형식이 아닙니다" 대신 깊이 때문에 건너뛰었다고 안내합니다.

## v7.1.27 · 파일별 묶음 보기만 사용, 머리줄 구분 강화

- 여러 파일 상세 목록은 파일별 묶음 방식만 씁니다. 맨 앞 파일 칸 방식과 설정 항목은 없앴습니다.
- 파일 머리줄 위에 여백과 굵은 윗선, 📄 아이콘을 넣고 그 아래 결과를 들여써서 파일 사이와 소속이 잘 보이게 했습니다.

## v7.1.26 · 여러 파일 상세 목록 파일별 묶음 보기

- 설정 → 일반 → 화면에 **여러 파일 상세 목록 보기**를 추가했습니다. **파일별 묶음**을 고르면 여러 파일을 골랐을 때 아래 검색 결과가 파일마다 경로·결과 수(일부만 검색했으면 그 이유) 머리줄과 그 아래 결과로 나뉘어 보입니다. 기본값은 지금처럼 **파일 칸**입니다.

## v7.1.25 · 상세 목록 열기 단추 제거, 기타 칸 글자색

- 아래 검색 결과 위의 **파일 열기**·**폴더 열기** 단추를 없앴습니다. 파일은 파일 목록에서 두 번 누르거나 마우스 오른쪽 메뉴로 열 수 있습니다.
- 파일 목록 기타 칸의 글자를 기본 글자색으로 바꿔 테마와 상관없이 잘 보이게 했습니다. ⚠ 아이콘만 강조색입니다.

## v7.1.24 · 여러 파일 결과 합쳐 보기, 파일 목록 기타 칸

- 파일 목록에서 여러 파일을 고르면(`Ctrl`·`Shift` 클릭, `Ctrl + A`) 아래 검색 결과에 고른 파일들의 결과를 이어서 보여 줍니다. 맨 앞에 파일 이름 칸이 생기고, 결과를 고르면 그 결과의 파일로 미리보기·열기를 합니다. 결과가 많아도 보는 페이지만 정리해 바로 뜹니다.
- 파일 목록에 **기타** 칸을 추가했습니다. 결과 수 제한 도달, 일부 글자를 읽지 못함, 너무 깊은 JSON 값 건너뜀, Excel 시트를 열지 못함처럼 일부만 검색한 파일의 이유를 짧게 보여 줍니다. 내보내기에도 함께 저장됩니다.
- 아래 검색 결과 끝에 붙던 "파일당 최대 검색 결과 도달" 안내 줄은 기타 칸으로 옮겨 없앴습니다.

## v7.1.23 · 그룹 개수 오른쪽 정렬

- 검색 폴더 그룹 머리글의 (선택/전체) 개수를 이름 바로 뒤가 아니라 줄 오른쪽 끝에 맞춰 표시합니다.

## v7.1.22 · 그룹 펼치기 단추 위치·끌기

- 검색 폴더 그룹의 ▸/▾ 단추를 체크와 이름 사이로 옮겼습니다.
- 이 단추 위에서 끌어도 그룹 순서를 바꿀 수 있습니다. 끌지 않고 누르면 이전처럼 접거나 펼칩니다.

## v7.1.21 · 라이트 모드 검색 중 빛 색 조정

- 라이트 모드에서 검색 중 요약 줄의 빛이 밝은 배경에 묻혀 잘 보이지 않던 것을, 주황빛으로 바꿔 잘 보이게 했습니다.

## v7.1.20 · 검색 중 요약 줄에 빛 흐름 표시

- 검색 중에는 요약 줄 안에서 밝은 빛이 왼쪽에서 오른쪽으로 흐르며 진행 중임을 보여 줍니다. 검색할 때만 요약 줄 아래에 나타나던 움직이는 막대는 없앴습니다.

## v7.1.19 · 체크 상자 밑줄 제거

- 체크 상자에 마우스를 올리면 아래에 파란 밑줄이 생기던 것을 없앴습니다.
- 어두운 테마에서 필터 목록의 체크 상자와 이름 사이가 넓게 벌어지던 것을 좁혔습니다.

## v7.1.18 · 필터 항목 이름을 누르면 체크 대신 선택

- 검색 폴더·확장자·파일명 목록에서 항목 이름을 눌러도 더는 체크가 바뀌지 않습니다. 체크는 체크 상자를 눌러 바꾸고, 이름을 누르면 그 항목이 선택되며 끌어서 순서를 바꿀 수 있습니다.

## v7.1.17 · 필터 항목 이름을 끌어서 순서 바꾸기

- 검색 폴더·확장자·파일명 목록에서 항목 이름 글자를 누른 채 끌어도 순서를 바꿀 수 있습니다. 움직이지 않고 누르면 이전처럼 체크가 바뀝니다.

## v7.1.16 · 마지막으로 보던 탭 복원

- 프로그램을 다시 켜면 닫기 전에 보던 탭이 보입니다. 이전에는 늘 맨 마지막 탭이 보였습니다.
- 검색 중 안내 글에 검색어를 서식으로 해석하지 않고 입력한 글자 그대로 보여 줍니다.

## v7.1.15 · 창 배치 높이 복원 수정

- 검색 설정 창 등의 높이를 바꾸고 프로그램을 다시 켜면 높이가 달라지던 문제를 고쳤습니다. 이제 마지막에 쓴 높이 그대로 열립니다.

## v7.1.14 · 결과 없음 안내에 검색 조건 표시

- 검색 결과가 없으면 이번 검색에 쓴 **검색 모드·검색 폴더·확장자 필터·파일명 필터**를 나열합니다. 폴더는 3개까지 보이고 나머지는 "외 N개"로 표시합니다. 검색 모드를 쓴 경우 강조하고, 확장자는 검색 모드가 정한 범위를 보여 줍니다.
- 한글 자모 분리(NFD)·다국어 대소문자 안내 문장을 뺐습니다. 인코딩 확인 안내는 남겼습니다.

## v7.1.13 · 검색 중 도는 표시 흔들림 수정

- 검색 중 요약 줄 앞의 도는 표시가 글꼴에 따라 좌우로 커졌다 작아지던 것을 고쳤습니다. 이제 크기가 고정된 원호가 매끄럽게 돕니다.

## v7.1.12 · 검색 중 표시 다듬기

- 검색 중 요약 줄 맨 앞에 도는 표시를 넣었습니다.
- 요약 줄 끝의 "결과가 계속 늘어납니다" 문구를 뺐습니다.

## v7.1.11 · 검색 중 안내 강화

- 검색 중에는 결과가 없어도 바로 요약 줄에 **검색 중…**과 확인한 파일 수·경과 시간을 보여 주고, 아래에 움직이는 막대를 표시합니다. 결과가 먼저 나와도 검색이 끝나지 않았음을 알 수 있습니다.
- 검색이 끝나면 막대가 사라지고 요약 줄이 초록색 **✓ 검색 완료**로 바뀝니다(예전에는 파란색).
- 다른 프로그램을 보고 있을 때 검색이 끝나면 작업 표시줄 아이콘이 깜빡입니다.
- 진행률(%)은 표시하지 않습니다. 전체 파일 수를 미리 세면 그만큼 검색이 느려지기 때문입니다.

## v7.1.10 · 검색 모드 사용 중 확장자 필터는 안내만 표시

- 검색 모드가 기본이 아닐 때 확장자 필터 영역에 흐리게 남아 있던 확장자 목록·입력칸·버튼을 숨기고 안내만 보입니다. 검색 모드를 쓰고 있다는 것을 바로 알 수 있습니다.
- 숨기기만 하므로 확장자 목록과 체크 여부는 바뀌지 않으며, 검색 모드를 기본으로 돌리면 그대로 다시 보입니다.

## v7.1.9 · 창 배치·열 너비도 모든 탭이 함께 사용

- 검색 설정·검색 폴더·필터 창의 위치(도크 배치), 결과 목록과 상세 목록 사이 구분선 위치, 결과 열 너비를 모든 탭이 같게 씁니다. 한 탭에서 바꾸고 다른 탭으로 옮겨 가면 그 탭에도 같은 배치가 적용됩니다.
- 바꾼 창 배치가 다음 실행 때도 유지됩니다. 예전에는 창 배치를 옮겨도 다시 켜면 기본 배치로 돌아갔습니다.

## v7.1.8 · 설정·검색 히스토리를 모든 탭이 함께 사용

- 한 탭에서 검색한 검색어가 다른 탭으로 옮겨 가면 그 탭의 검색 히스토리에도 바로 나타납니다. 예전에는 목록을 펼치기 전까지 이전 목록이 남아 있었습니다.
- 결과 미리보기의 앞뒤 줄 수를 한 탭에서 바꾸면, 다른 탭으로 옮겨 갔을 때 그 탭에도 같은 값이 적용됩니다.

## v7.1.7 · 새 탭이 현재 탭 구성을 이어받음

- 새 탭을 열면 그때 보고 있던 탭의 검색 폴더·폴더 그룹·확장자·파일명 필터를 그대로 이어받습니다. 예전에는 "마지막으로 필터를 바꾼 탭"의 값으로 열려, 어느 탭의 구성이 올지 알기 어려웠습니다.
- 새 탭의 검색어는 비어 있고 검색 모드는 기본으로 열립니다.

## v7.1.6 · 진단 도구 제거

- 설정 → 고급의 **시스템 자가 진단**과 **성능 진단**을 없앴습니다. 자가 진단은 프로그램이 켜져 있으면 늘 같은 결과(정상)였고, 성능 진단은 파일을 하나씩 따로 재서 실제 검색 속도와 달라 판단에 쓰기 어려웠습니다.
- 검색이 느리거나 결과가 이상할 때는 상태 표시줄의 **로그**와 건너뛴 파일 목록을 확인하세요.

## v7.1.5 · 필터 저장 다듬기

- 결과가 아주 많은 검색이 끝난 직후 필터를 바꾸면 저장이 끝날 때까지 화면이 잠깐(1초 안쪽) 멈추던 것을 고쳤습니다. 필터 저장도 백그라운드에서 합니다.
- 새 탭을 만들 때, 예전에 복원되지 못한 같은 이름 탭의 필터가 붙지 않습니다.
- 이전 버전에서 저장한 탭을 열 때 폴더가 하나도 없는 빈 그룹이 생기지 않습니다.

## v7.1.4 · 검색하지 않아도 바꾼 필터 저장

- 폴더·폴더 그룹·확장자·파일명 필터·검색 모드를 바꾸면, 검색하지 않아도 잠시 뒤 그 탭의 값으로 저장합니다. 예전에는 검색이 끝나거나 프로그램을 정상 종료할 때만 탭에 저장되어, 그 사이에 PC가 꺼지거나 강제 종료되면 마지막 검색 이후에 바꾼 내용이 되돌아갔습니다.
- 7.1.3에서 그룹이 없는 탭에 설정의 그룹을 붙이던 방식은 이전 버전이 저장한 탭에만 씁니다. 이제 탭마다 그룹을 다르게 써도 다른 탭의 그룹이 붙지 않습니다.

## v7.1.3 · 폴더 그룹이 사라지던 문제 수정

- 검색한 뒤 폴더 그룹을 만들고 프로그램이 정상 종료 없이 꺼지면(PC 종료, 강제 종료 등), 다음에 켤 때 폴더 그룹이 사라지던 문제를 고쳤습니다. 폴더 목록은 그대로였고 그룹만 없어졌습니다. 6.3.9부터 있던 문제입니다.
- 이제 탭을 복원할 때 저장된 탭에 그룹 정보가 없으면, 설정에 저장된 그룹을 씁니다. 이미 사라진 그룹은 되살리지 못하므로 다시 만들어야 합니다.

## v7.1.1 · 2차 안정 버전 (Rust 단일 엔진)

7.1.1을 두 번째 안정 버전으로 지정합니다(2026-11-13). 코드는 6.4.20과 같고, 버전 번호와 기록 체계만 새로 시작합니다. 고정 문서는 [master-baseline-v7.1.1.md](master-baseline-v7.1.1.md)입니다.

1차 안정 버전 6.4.1 이후 바뀐 주요 내용은 다음과 같습니다. 버전별 세부는 보관된 이력을 보세요.

- **검색 엔진 하나로 통합:** 모든 검색을 Rust 엔진 하나로 합니다. 예전의 "글자 변형 검색"(Python, 느림)과 검색 방식 선택이 없어졌고, 기본 검색이 그 비교를 모두 합니다. 대상은 대소문자 전체 규칙(`Straße` = `strasse`), 분해형 한글(NFD), CP949·UTF-16 파일, JSON·XML·Excel·UE archive 값입니다.
- **속도:** 6.4.1보다 한글 검색어는 최대 약 2.6배, CP949 파일은 약 2배, UTF-16 파일은 약 1.3~1.7배, 구조화 파일 값 검색은 항목에 따라 약 1.1~2.3배 빨라졌습니다. 바이너리가 많은 폴더의 한글 검색, 일치가 아주 많은 검색의 결과 정리도 빨라졌습니다.
- **검색 모드 선택:** 검색줄 왼쪽 콤보 박스에서 기본·JSON·XML·Excel·archive 값만 검색을 고릅니다.
- **필터 표시:** 확장자·파일명 필터를 탭이나 위아래로 함께 볼 수 있습니다(기본은 탭).
- **정확성:** 일부를 해석하지 못한 파일은 안내로 알립니다. 정확히 일치 검색은 검색어 앞뒤 공백을 무시합니다. JSON 키의 `/`는 중첩 경로와 구분해 보여 줍니다. 상세 목록의 강조가 검색과 같은 기준을 씁니다.
- **화면·안정성:** 검색 종료 후 저장을 백그라운드에서 해 화면이 멈추지 않습니다. 정렬 순서가 실행마다 바뀌지 않습니다. 전체 결과 상한에 닿으면 엔진이 바로 멈춥니다. 탭 이름 중복, 데이터 삭제 후 재저장, Excel 저장 실패 같은 문제를 고쳤습니다.
