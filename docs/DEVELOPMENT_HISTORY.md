# StringFinder 버전별 개발 히스토리

7.1.1부터 새로 기록합니다. 6.4.20까지의 이력은 [v7 이전 개발 히스토리](archive/before-v7/DEVELOPMENT_HISTORY.md)에 있습니다.

## v7.1.13 · 검색 중 도는 표시 흔들림 수정

- 검색 중 요약 줄 앞의 도는 표시가 글꼴에 따라 좌우로 커졌다 작아지던 것을 고쳤습니다. 이제 크기가 고정된 원호가 매끄럽게 돕니다.

## v7.1.12 · 검색 중 표시 다듬기

- 검색 중 요약 줄 맨 앞에 도는 표시를 넣었습니다.
- 요약 줄 끝의 "결과가 계속 늘어납니다" 문구를 뺐습니다.

## v7.1.11 · 검색 중 안내 강화

- 검색 중에는 결과가 없어도 바로 요약 줄에 **검색 중…**과 확인한 파일 수·경과 시간을 보여 주고, 아래에 움직이는 막대를 표시합니다. 결과가 먼저 나와도 검색이 끝나지 않았음을 알 수 있습니다.
- 검색이 끝나면 막대가 사라지고 요약 줄이 초록색 **✓ 검색 완료**로 바뀝니다(예전에는 파란색).
- 다른 프로그램을 보고 있을 때 검색이 끝나면 작업 표시줄 아이콘이 깜빡입니다.
- 진행률(%)은 표시하지 않습니다. 전체 파일 수를 미리 세면 그만큼 검색이 느려지기 때문입니다.

## v7.1.10 · 검색 모드 사용 중 확장자 필터는 안내만 표시

- 검색 모드가 기본이 아닐 때 확장자 필터 영역에 흐리게 남아 있던 확장자 목록·입력칸·버튼을 숨기고 안내만 보입니다. 검색 모드를 쓰고 있다는 것을 바로 알 수 있습니다.
- 숨기기만 하므로 확장자 목록과 체크 여부는 바뀌지 않으며, 검색 모드를 기본으로 돌리면 그대로 다시 보입니다.

## v7.1.9 · 창 배치·열 너비도 모든 탭이 함께 사용

- 검색 설정·검색 폴더·필터 창의 위치(도크 배치), 결과 목록과 상세 목록 사이 구분선 위치, 결과 열 너비를 모든 탭이 같게 씁니다. 한 탭에서 바꾸고 다른 탭으로 옮겨 가면 그 탭에도 같은 배치가 적용됩니다.
- 바꾼 창 배치가 다음 실행 때도 유지됩니다. 예전에는 창 배치를 옮겨도 다시 켜면 기본 배치로 돌아갔습니다.

## v7.1.8 · 설정·검색 히스토리를 모든 탭이 함께 사용

- 한 탭에서 검색한 검색어가 다른 탭으로 옮겨 가면 그 탭의 검색 히스토리에도 바로 나타납니다. 예전에는 목록을 펼치기 전까지 이전 목록이 남아 있었습니다.
- 결과 미리보기의 앞뒤 줄 수를 한 탭에서 바꾸면, 다른 탭으로 옮겨 갔을 때 그 탭에도 같은 값이 적용됩니다.

## v7.1.7 · 새 탭이 현재 탭 구성을 이어받음

- 새 탭을 열면 그때 보고 있던 탭의 검색 폴더·폴더 그룹·확장자·파일명 필터를 그대로 이어받습니다. 예전에는 "마지막으로 필터를 바꾼 탭"의 값으로 열려, 어느 탭의 구성이 올지 알기 어려웠습니다.
- 새 탭의 검색어는 비어 있고 검색 모드는 기본으로 열립니다.

## v7.1.6 · 진단 도구 제거

- 설정 → 고급의 **시스템 자가 진단**과 **성능 진단**을 없앴습니다. 자가 진단은 프로그램이 켜져 있으면 늘 같은 결과(정상)였고, 성능 진단은 파일을 하나씩 따로 재서 실제 검색 속도와 달라 판단에 쓰기 어려웠습니다.
- 검색이 느리거나 결과가 이상할 때는 상태 표시줄의 **로그**와 건너뛴 파일 목록을 확인하세요.

## v7.1.5 · 필터 저장 다듬기

- 결과가 아주 많은 검색이 끝난 직후 필터를 바꾸면 저장이 끝날 때까지 화면이 잠깐(1초 안쪽) 멈추던 것을 고쳤습니다. 필터 저장도 백그라운드에서 합니다.
- 새 탭을 만들 때, 예전에 복원되지 못한 같은 이름 탭의 필터가 붙지 않습니다.
- 이전 버전에서 저장한 탭을 열 때 폴더가 하나도 없는 빈 그룹이 생기지 않습니다.

## v7.1.4 · 검색하지 않아도 바꾼 필터 저장

- 폴더·폴더 그룹·확장자·파일명 필터·검색 모드를 바꾸면, 검색하지 않아도 잠시 뒤 그 탭의 값으로 저장합니다. 예전에는 검색이 끝나거나 프로그램을 정상 종료할 때만 탭에 저장되어, 그 사이에 PC가 꺼지거나 강제 종료되면 마지막 검색 이후에 바꾼 내용이 되돌아갔습니다.
- 7.1.3에서 그룹이 없는 탭에 설정의 그룹을 붙이던 방식은 이전 버전이 저장한 탭에만 씁니다. 이제 탭마다 그룹을 다르게 써도 다른 탭의 그룹이 붙지 않습니다.

## v7.1.3 · 폴더 그룹이 사라지던 문제 수정

- 검색한 뒤 폴더 그룹을 만들고 프로그램이 정상 종료 없이 꺼지면(PC 종료, 강제 종료 등), 다음에 켤 때 폴더 그룹이 사라지던 문제를 고쳤습니다. 폴더 목록은 그대로였고 그룹만 없어졌습니다. 6.3.9부터 있던 문제입니다.
- 이제 탭을 복원할 때 저장된 탭에 그룹 정보가 없으면, 설정에 저장된 그룹을 씁니다. 이미 사라진 그룹은 되살리지 못하므로 다시 만들어야 합니다.

## v7.1.1 · 2차 안정 버전 (Rust 단일 엔진)

7.1.1을 두 번째 안정 버전으로 지정합니다(2026-11-13). 코드는 6.4.20과 같고, 버전 번호와 기록 체계만 새로 시작합니다. 고정 문서는 [master-baseline-v7.1.1.md](master-baseline-v7.1.1.md)입니다.

1차 안정 버전 6.4.1 이후 바뀐 주요 내용은 다음과 같습니다. 버전별 세부는 보관된 이력을 보세요.

- **검색 엔진 하나로 통합:** 모든 검색을 Rust 엔진 하나로 합니다. 예전의 "글자 변형 검색"(Python, 느림)과 검색 방식 선택이 없어졌고, 기본 검색이 그 비교를 모두 합니다. 대상은 대소문자 전체 규칙(`Straße` = `strasse`), 분해형 한글(NFD), CP949·UTF-16 파일, JSON·XML·Excel·UE archive 값입니다.
- **속도:** 6.4.1보다 한글 검색어는 최대 약 2.6배, CP949 파일은 약 2배, UTF-16 파일은 약 1.3~1.7배, 구조화 파일 값 검색은 항목에 따라 약 1.1~2.3배 빨라졌습니다. 바이너리가 많은 폴더의 한글 검색, 일치가 아주 많은 검색의 결과 정리도 빨라졌습니다.
- **검색 모드 선택:** 검색줄 왼쪽 콤보 박스에서 기본·JSON·XML·Excel·archive 값만 검색을 고릅니다.
- **필터 표시:** 확장자·파일명 필터를 탭이나 위아래로 함께 볼 수 있습니다(기본은 탭).
- **정확성:** 일부를 해석하지 못한 파일은 안내로 알립니다. 정확히 일치 검색은 검색어 앞뒤 공백을 무시합니다. JSON 키의 `/`는 중첩 경로와 구분해 보여 줍니다. 상세 목록의 강조가 검색과 같은 기준을 씁니다.
- **화면·안정성:** 검색 종료 후 저장을 백그라운드에서 해 화면이 멈추지 않습니다. 정렬 순서가 실행마다 바뀌지 않습니다. 전체 결과 상한에 닿으면 엔진이 바로 멈춥니다. 탭 이름 중복, 데이터 삭제 후 재저장, Excel 저장 실패 같은 문제를 고쳤습니다.
