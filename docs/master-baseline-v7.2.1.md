# 3차 안정 버전 — v7.2.1

선언일: **2026-11-15** · 이전 기준판: [v7.1.1](master-baseline-v7.1.1.md)

v7.2.1을 StringFinder의 세 번째 안정 버전으로 지정합니다. 코드는 7.1.34와 같고 버전 표기만 7.2.1로 올려 다시 빌드했습니다. 7.1.1 이후 화면과 사용 방식이 많이 바뀌어 두 번째 숫자를 올렸습니다(사용자 지정). 검색 엔진은 7.1.1과 같습니다. 이 문서는 선언 뒤에는 오탈자·깨진 링크만 고칩니다.

## 기준 소스와 배포물

- 기준 태그: `v7.2.1`. 이 태그는 이 고정 문서를 추가한 선언 커밋을 가리킵니다.
- 제품 기준 커밋(7.1.34 코드): `3d3e9e09ad497084331d97a20a944ad28e4280eb`. 선언 커밋은 여기에 버전 표기·문서만 더합니다.
- 배포 파일: `StringFinder-v7.2.1.exe` (Windows 단일 실행 파일). `dist/StringFinder.exe`는 이 파일의 사본입니다.

## v7.1.1 이후 바뀐 기능

- **검색 엔진:** 바뀌지 않았습니다. 같은 표본의 검색 결과가 7.1.1과 같고, 새로 잰 기준선은 7.1.1 기준선의 0.81~1.00배입니다([성능 기록](PERFORMANCE_HISTORY.md)).
- **여러 파일 결과 합쳐 보기:** 파일 목록에서 여러 파일을 고르면(`Ctrl`·`Shift` 클릭, `Ctrl + A`) 아래 검색 결과가 파일별 📄 머리줄과 그 아래 결과로 이어집니다. 결과가 많아도 보는 페이지만 정리해 바로 뜨고, 결과를 고르면 그 결과의 파일로 미리보기·열기를 합니다.
- **파일 목록 기타 칸:** 결과 수 제한 도달, 일부 글자를 읽지 못함, 너무 깊은 JSON 값 건너뜀, Excel 시트를 열지 못함처럼 일부만 검색한 파일의 이유를 보여 줍니다. 상세 목록의 안내 줄은 없앴습니다.
- **설정 내보내기·불러오기:** 설정, 창 크기, 검색 조건, 검색어 기록을 파일 하나로 옮깁니다. 불러올 때 StringFinder 파일인지 확인하고, 묶음을 골라 가져오며, 예전 버전 파일도 지금 형식으로 맞춥니다. 불러오면 백업 뒤 프로그램이 종료되고 다시 시작할 때 적용됩니다.
- **탭과 공통 설정:** 새 탭이 보던 탭의 폴더·그룹·필터를 이어받습니다. 설정·검색 기록·창 배치·열 너비를 모든 탭이 함께 쓰고, 다시 켜면 마지막으로 보던 탭과 창 배치가 그대로 돌아옵니다. 필터는 검색하지 않아도 바로 저장됩니다.
- **검색 중 표시:** 요약 줄이 노란색으로 확인한 파일 수·경과 시간과 도는 표시, 흐르는 빛을 보여 주고, 끝나면 초록 "✓ 검색 완료"로 바뀝니다. 다른 프로그램을 보고 있으면 작업 표시줄이 깜빡입니다. 결과가 없으면 사용한 검색 조건을 나열합니다.
- **왼쪽 목록:** 이름을 누르면 체크 대신 선택되고 이름·손잡이를 끌어 순서를 바꿉니다. 폴더 그룹의 ▸/▾ 단추는 체크와 이름 사이, 개수는 줄 오른쪽에 있습니다. 지금 PC에 없는 폴더에는 ⚠가 붙습니다. 값만 검색 모드에서는 확장자 목록 대신 안내만 보입니다.
- **설정 창:** 일반(화면·줄 열기 프로그램·설정 관리)과 고급(공통·로그·데이터)으로 정리했습니다. 진단 도구는 없앴습니다.
- **그 밖:** 파일 위치 열기 실패 안내, 깊은 UE archive를 형식 오류 대신 깊이 제한으로 안내, 큰 상세 목록 거르기는 입력이 멈춘 뒤 한 번만.
- **호환:** 7.1.1의 설정·세션 파일을 그대로 엽니다.

## 알려진 제약

- JSON 키 안의 `.`은 중첩 경로와 같은 글자로 보입니다.
- 머리글 정렬 기준은 세션에 저장되지 않습니다.
- 결과가 아주 많을 때 백그라운드 저장 중(1~2초) 화면 반응이 조금 느려질 수 있습니다.
- 수천 개 파일(수십만 건)을 한꺼번에 고른 상태에서 상세 목록을 거르면 입력이 멈춘 뒤 1~2초 걸립니다.
- 검색이 진행 중일 때 결과가 들어와 파일 목록이 다시 만들어지면, 여러 개 고른 선택이 보던 파일 하나로 풀립니다.
