# v8 이전 기록 (보관)

StringFinder 8.1.1을 안정 버전으로 지정하면서(2026-11-27) 7.x의 기록을 이 폴더로 옮겼습니다. 8 버전부터 검색 엔진의 버전을 앱 버전과 따로 매기고(엔진 1.0.0), 엔진이 지금 소스로 빌드됐는지를 소스 지문으로 확인합니다. 그래서 앱 버전과 엔진 버전이 같다는 전제로 쓴 7.x 기록을 현재 문서에서 분리했습니다.

이 폴더의 문서는 옮긴 당시 내용 그대로이며 깨진 링크만 고칩니다. 문서 안의 "현재", "기준" 같은 표현은 작성 당시를 뜻합니다.
