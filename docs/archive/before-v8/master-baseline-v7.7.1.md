# 8차 안정 버전 — v7.7.1

선언일: **2026-11-26** · 이전 기준판: [v7.6.1](master-baseline-v7.6.1.md)

v7.7.1을 StringFinder의 여덟 번째 안정 버전으로 지정합니다. 코드는 7.6.9와 같고 버전 표기만 7.7.1로 올려 다시 빌드했습니다. 두 번째 숫자는 사용자가 정했습니다. 이 문서는 선언 뒤에는 오탈자·깨진 링크만 고칩니다.

## 기준 소스와 배포물

- 제품 기준 커밋(7.6.9 코드): `f3dc4dda7ebca0bd62f53f3c54e21ce905313203`. 선언 커밋은 여기에 버전 표기·문서·벤치마크 기준선만 더합니다.
- 배포 파일: `StringFinder-v7.7.1.exe` (Windows 단일 실행 파일). `dist/StringFinder.exe`는 이 파일의 사본입니다.

## v7.6.1 이후 바뀐 기능

검색 엔진(Rust) 코드는 7.6.1과 같고, 모두 화면 동작 변경입니다.

- **검색 폴더 목록(7.6.3~7.6.5)**
  - 그룹 머리글을 고르고 `F2`를 누르면 이름 바꾸기 창이 뜹니다. 오른쪽 메뉴에 `F2`가 표시됩니다.
  - 그룹의 `(선택/전체)` 개수가 줄 오른쪽 끝(× 앞)에 그룹 이름과 같은 색으로 보입니다.
  - 목록은 보이는 폭에 맞춰져 가로 스크롤이 없습니다. 창을 좁혀도 개수는 가려지지 않고, 긴 그룹 이름은 끝을, 긴 폴더 경로는 가운데를 "…"로 줄입니다(예: `D:/Project/…/Game/ko`). 마우스를 올리면 전체 이름이 보이고, 없는 폴더는 전체 경로와 안내가 함께 보입니다.
  - 이름·개수·⚠ 글자가 줄의 세로 가운데에 옵니다.
- **검색 상세 칸별 복사(7.6.3)**
  - 오른쪽 메뉴에 칸 하나만 복사하는 항목이 있습니다.
  - 일반 검색은 **위치만 복사**(줄 번호 또는 `시트!셀`)·**내용만 복사**입니다.
  - 다른 검색 방식은 열 이름마다 하나씩입니다(예: JSON은 위치·키·값).
  - 여러 파일 묶음 보기의 파일 머리줄에는 이 메뉴가 뜨지 않습니다.
- **파일 목록 선택과 상세 목록(7.6.2·7.6.6~7.6.8)**
  - 목록이 다시 만들어질 때(결과 추가·정렬·페이지 이동·필터) 상세를 정하는 규칙이 하나입니다.
    - 고른 파일이 보이면 상세는 그 선택을 따릅니다.
    - 고른 파일이 없으면 상세에서 필터 결과에 없는 파일만 빼고, 하나도 남지 않으면 비웁니다.
    - 페이지를 넘겨도 상세가 남습니다.
  - Ctrl+클릭으로 선택을 모두 풀면 직전 상세를 유지합니다.
  - 고른 파일이 없어도 상세가 무언가를 보여 주고 있으면, 검색 종료·정렬 완료 때 첫 파일을 자동으로 고르지 않습니다.
- **화면 여백(7.6.4·7.6.9)**
  - 로그 창: 안쪽 여백과 로그 글자 둘레 여백을 넓히고, 처음 크기를 1100×680으로 키웠습니다.
  - 상태 표시줄: 검색 설정 글자가 왼쪽 테두리에서 떨어집니다.
  - 필터: 확장자·파일명 그룹 제목 위에 여백이 있습니다.
- **검색 결과:** 33개 벤치마크 표본의 결과 지문·일치 수가 7.6.1과 같습니다. 속도는 [성능 기록](PERFORMANCE_HISTORY.md)에 있습니다.

## 업데이트할 때

- 세션 저장 형식은 7.6.1과 같습니다(형식 3). 7.6.1에서 저장한 탭은 결과와 함께 그대로 열리고, 7.7.1에서 저장한 탭도 7.6.1에서 열립니다.
- 7.2.1 이전 버전에서 저장한 탭은 7.6.1과 마찬가지로 검색 조건만 불러오고 결과는 한 번 비워집니다.

## 알려진 제약

- UTF-16·CP949 archive는 검색하는 동안 파일 전체의 UTF-8 사본을 만들어, 수 GB 파일은 메모리가 부족하면 건너뜁니다.
- JSON 키 안의 `.`은 중첩 경로와 같은 글자로 보입니다.
- 머리글 정렬 기준과 검색 상세에서 직접 끈 열 비율은 저장되지 않습니다(프로그램을 다시 켜면 기본값).
- 결과가 아주 많을 때 백그라운드 저장 중(1~2초) 화면 반응이 조금 느려질 수 있습니다.
- 수천 개 파일(수십만 건)을 한꺼번에 고른 상태에서 상세 목록을 거르면 입력이 멈춘 뒤 1~2초 걸립니다.

성능 기준값은 [벤치마크 기준선](../../BENCHMARK_BASELINE.md), 버전별 변경은 [개발 히스토리](DEVELOPMENT_HISTORY.md)에 있습니다.
