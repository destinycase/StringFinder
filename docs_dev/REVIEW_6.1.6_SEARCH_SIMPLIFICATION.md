# 6.1.6 검색 옵션 단순화 검증

## 검증 범위

존재 확인 전용 UI·Python·Rust·결과 표시·진단을 제거하고, 파일명 쉼표 묶음과 상태 표시줄의 적용 조건을 검증했다. 일반 텍스트의 무결과 사전 검사는 유지했다. 과거 존재 확인 결과는 명시된 메타데이터가 있을 때만 비우며, 실제 내용이나 현재 입력 옵션으로 과거 결과를 추측하지 않는다.

## 테스트와 화면

- 전체 Python: 1,107 통과, 2 건너뜀. 윤초를 Python 날짜로 표현하지 못한다는 기존 경계 표본 경고 4건은 유지한다.
- Rust: 64 통과. Clippy all-targets 경고 없음, 포맷 검사와 Ruff 통과.
- 제거된 기능의 전용 테스트/파라미터만 정리하고 일반/누락 방지 파일 집합·결과 수·손상 문서·인코딩·취소 검증은 유지했다. 구형 API 7 엔진 거부 검증도 유지했다.
- 한국어·영어, 1280×640 논리 크기와 150% 배율에서 한 줄 검색 설정, 상태 표시줄, 도움말/로그/설정 버튼을 확인했다. 실제 디스플레이별 수동 검증을 대체하지 않는다.

## 속도와 결과 무결성

이전 커밋의 6.1.5 엔진과 현재 6.1.6 엔진을 같은 프로세스에 로드하고 순서를 번갈아 측정했다. 텍스트 2개 및 밀집·희소·수식 결과·날짜 Excel 각 4개 조건(18개)을 7회, JSON 5개 조건을 단독 31회 측정했다. JSON은 중복 키 허용/금지 정책 모두 내용·행·오프셋·길이 지문을 대조했다. 모든 지문이 일치했다.

병행 검증 중 첫 JSON 측정은 일부 조건에서 13~20% 편차가 있어 단독 31회로 재측정했다. 기본 중복 키 금지 정책의 재측정 중앙값은 아래와 같다. 이 결과는 UI·워커 시작이나 실제 디스크 냉간 검색 전체 시간이 아니다.

| JSON 조건 | 6.1.5 ms | 6.1.6 ms | 변화 |
| --- | ---: | ---: | ---: |
| 반복 적중 | 23.483 | 24.998 | +6.5% |
| 드문 적중 | 54.117 | 52.688 | -2.6% |
| 무결과 | 52.961 | 52.642 | -0.6% |
| 이스케이프 키 | 13.433 | 13.536 | +0.8% |
| 넓은 객체 | 4.499 | 4.878 | +8.4% |

텍스트 적중/무결과는 +4.5%/-2.6%, 밀집·수식·날짜 Excel은 -3.1%~+3.1%였고, 1ms 미만 희소 Excel은 -7.9%~+7.0%였다. 최종 바이너리 재측정에서 반복 적중은 약 1.5ms(+6.5%), 넓은 객체는 약 0.4ms(+8.4%) 증가했다. 일부 표본의 작은 비용 증가는 남아 있으며 실제 폴더 전체 검색 회귀와 동일시하지 않는다. 속도 개선을 주장하는 변경은 아니다. 별도 Excel 제품 경로 검증은 32개 조합을 준비 실행 후 3회씩 수행하여 정상 결과·좌표·값을 확인했다.

## 남은 제약

여러 파일의 순차 진단은 실제 병렬 검색 전체 시간을 나타내지 않는다. A–J D의 예전 조기 종료 측정과 현재 전체 검색을 직접 비교하지 않는다. 6.1.1 기준선의 원본 측정은 수정하지 않고 현재 지원되는 판정 조합과 구분했다. 이전 기능의 표시 문자열만 남은 메타데이터 없는 세션은 실제 내용과 구분할 수 없어 임의로 삭제하지 않는다.

최종 JSON 측정 엔진 SHA-256: `95fe4df5073f86d72e1b62df9655a7d2c0d203101e597e2bd3d0722d6e5cba51`. 원본 반복값은 `benchmark_6.1.6_search_simplification.json`에 보존한다.
