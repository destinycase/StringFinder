# String Finder

Python의 가용 자원을 최대 활용하여 극강의 검색 속도를 제공하는 문자열 검색 도구입니다.

## 주요 특징

- **초고속 텍스트 검색**: `mmap`과 바이트 수준 정규식 검색, 지연 디코딩(Lazy Decoding)을 통해 대용량 파일도 성능 저하 없이 즉시 스캔합니다.
- **Excel 하이브리드 검색 엔진**: 파일 크기에 따라 Calamine(고속)과 Openpyxl Streaming(저메모리) 엔진을 자동으로 전환하여 2GB 이상의 엑셀 파일도 안전하게 검색합니다.
- **가상 스크롤(Virtual Scroll) UI**: `Model/View` 아키텍처를 도입하여 100만 건 이상의 검색 결과도 UI 프리징 없이 부드럽게 스크롤 및 정렬할 수 있습니다.
- **하이브리드 병렬 파일 스캔**: 전 구간 병렬 재귀 탐색과 시스템 콜 최적화(Hybrid Scanning)를 통해 대규모 디렉토리도 수 초 내에 스캔 완료합니다.
- **실시간 결과 필터링**: `QSortFilterProxyModel`을 사용하여 수만 건의 검색 결과 내에서 파일명으로 실시간 필터링이 가능합니다. [NEW]
- **다중 파일명 필터**: 콤마(,)와 와일드카드를 사용하여 `npc, fo*`와 같이 여러 개의 파일명 필터를 동시에 적용할 수 있습니다. [NEW]
- **대소문자 무시(Case-insensitive)**: 검색 효율성을 극대화하기 위해 항상 대소문자를 무시하고 검색하며, 대용량 파일 검색 성능을 한 단계 더 끌어올렸습니다.
- **강력한 인코딩 및 BOM 대응**: UTF-8-BOM, CP949, UTF-16(LE/BE) 등 다양한 인코딩과 BOM을 자동으로 감지하고 정확하게 검색합니다.
- **모던 UI 및 편의성**: `qdarktheme` 기반의 다크/라이트 모드, 실시간 프리뷰, 검색 히스토리 및 직관적인 가이드 문구를 제공합니다.

## 설치 및 실행

### 요구사항
- Windows OS (추천)
- Python 3.12 이상

### 설치
```bash
pip install -r requirements.txt
```

### 실행
```bash
python run.py
```
